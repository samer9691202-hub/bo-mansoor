نظام بو منصور V20 — تطوير قسمي عروض الأسعار والفواتير

التطويرات:
- لوحة مؤشرات مختصرة لعروض الأسعار والفواتير.
- تحسين سجل عروض الأسعار والفواتير وترتيب البيانات.
- إضافة بحث فوري وتصفية حسب الحالة في القسمين.
- إبراز إجمالي الفواتير والمقبوضات والمتبقي.
- تحسين عرض الإجراءات لتناسب الشاشات الصغيرة.
- المحافظة على الوظائف الحالية للتعديل والاعتماد وتسجيل الدفعات والطباعة/PDF.

حدود التعديل:
- التعديل محصور في واجهات إدارة عروض الأسعار والفواتير داخل التطبيق وCSS الخاص بهما.
- لم يتم تعديل قوالب HTML الخاصة بمستند الفاتورة أو عرض السعر.
- لم يتم تعديل مقاس A4 أو كود المعاينة والطباعة وتصدير PDF والمشاركة.
- لم يتم تعديل بنية قاعدة البيانات.

يرجى تجربة النسخة داخل التطبيق قبل اعتمادها نهائيًا.
